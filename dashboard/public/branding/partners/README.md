# Homepage partner assets

These presentation assets are derived from the operator-provided files in the
repository's root `public/` directory. Next.js serves the copies here from
`/branding/partners/`.

- `feixiaohao-mark.svg`: original SVG with its viewBox restricted to the logo mark.
- `waytoweb4-mark.webp`: cropped logo mark, resized from `waytoweb4-logo.png`.
- `waytoweb4-orbit-mark.webp`: transparent version of that mark for the animated
  orbital scene; the black background is converted to alpha.
- `tintinland-mark.webp`: cropped colored icon, resized from `Tintinland-logo.png`.
- `cddjap-logo.jpg`: unchanged copy of the supplied image, which reads
  "Draper Dragon". The homepage labels this community entry explicitly as CDDJAP.

Feixiaohao and WayToWeb4 are the represented organizations. TinTinLand and CDDJAP
are displayed as community partners, not investors or event organizers.

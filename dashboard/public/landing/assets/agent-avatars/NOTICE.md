# Role portraits

These twenty fictional Agent portraits were generated for Nerya through ChatGPT's web interface using the GPT Pro Think skill and Ego browser, with Latest and Extra high selected.

The original Nerya mascot and pixel-cat insignia were uploaded as reference images. The completed 5×4 character atlas was visually inspected, then cropped into twenty separate 256px PNG files. No replacement character art was drawn during post-processing.

This set replaces the earlier DiceBear artwork. It does not inherit that artwork's CC0 attribution or license. See the project's LICENSE for the project terms.

`provenance.json` records the source conversation, uploaded reference hashes, atlas hash, crop rectangles and output hashes. The original generated atlas and prompt are retained under `assets/generated/mascot-roles/` and `docs/mascot-roles-sheet.md`.

The landing, embedded demo and dashboard serve matching local files. No avatar service is called at runtime.

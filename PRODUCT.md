# Product

## Register

product

## Users and purpose

Nerya's console is for operators managing trading agents, strategies, evidence,
and approvals. Memory and learning lets operators inspect what an agent retains,
correct it, and review proposed improvements without mixing strategy experience.

## Product character

Clear, restrained, practical. Preserve the existing console design system.

## Design principles

- Put the current task and its content ahead of explanations and configuration.
- Show secondary details and advanced controls only when requested.
- Keep scope, pending edits, failures, and consequential actions understandable.
- Preserve memory isolation and proposal approval boundaries in every view.
- Reuse existing controls, typography, semantic colors, and bilingual copy.

## Anti-references

Avoid repeated explanatory cards, competing primary buttons, implementation
identifiers as headlines, and presenting every advanced tool at the same level.

## Accessibility

Preserve keyboard operation, visible focus, labelled controls, readable contrast,
responsive layouts, reduced-motion support, and distinct loading/error/empty states.

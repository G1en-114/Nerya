# 1.0.0 Beta product-tour recordings

These English/Chinese, light/dark recordings are copied from the latest Nerya
website's `assets/product-recordings/strategy-*.gif` assets. The accompanying
original `.manifest.json` files record the source inputs, recording time and output
SHA-256 hashes. The README uses native HTML `<picture>` theme selection.

The recording target is the isolated product-tour DOM, with **synthetic example
data**. It does not call a live model, connect an account or execute an order.
These assets illustrate the interface; they are not evidence of live performance
or a successful desktop installer test.
